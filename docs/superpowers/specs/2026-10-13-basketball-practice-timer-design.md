# バスケットボール練習タイマー：初版の設計

日付：2026-10-13（日本時間）

## 目的と開発環境

個人のバスケットボール練習で、ドリブルなどを指定時間ずつ繰り返すための Web アプリを作る。iPhone SE のホーム画面から開いて使うことを主な利用形態とする。小さい画面でも残り時間が大きく読め、音で練習と休憩の切り替えを判断できることを重視する。

このクラウド環境で実装、ビルド、自動テスト、ブラウザ検証を行う。ユーザーの iPhone の OS バージョンは未確認であり、特定のバージョンを前提にせず機能の有無を検出する。Safari 実機の音、画面維持、ホーム画面追加の最終確認は iPhone SE で行う。

既存のチェックアウトを使う。ユーザーから依頼がない限り Git worktree は作らない。

## 合意した仕様

- 練習時間、練習間の休憩時間、セット数を設定できる。
- 1セットは練習1回。右と左を組み合わせて1セットとは数えない。
- 初期値は練習40秒、休憩5秒、3セット。
- 例：練習40秒 → 休憩5秒 → 練習40秒 → 休憩5秒 → 練習40秒 → 完了。合計2分10秒。最後のセットの後に休憩は入れない。
- エンドレスを選べる。自分で終了するまで練習と休憩を繰り返す。
- 開始、一時停止、再開、終了を操作できる。
- 練習終了、次の練習開始、全セット完了を異なる音で知らせる。
- 実行中は利用可能なら自動ロックを防ぐ。
- 別アプリへの移動や手動ロックで画面が非表示になった場合、一時停止する。戻った後はユーザーの操作で再開する。
- 設定は端末に保存する。ログイン不要。
- 初回のオンライン利用で必要なファイルが保存された後は、オフラインで使えるようにする。

## 画面とデザイン

### 共通

黒に近い背景と明るい文字を使い、練習中はオレンジ、休憩中は落ち着いたグリーンをアクセントにする。数字、余白、タイポグラフィを主役にし、装飾は読みやすさを妨げない範囲に抑える。外部フォントに依存せず、システムフォントと等幅の数字で表示を安定させる。

320px の狭い画面から動作するレスポンシブ設計とする。iPhone SE を想定する375px幅を重点的に確認する。画面の安全領域、縦横向き、Safari の画面サイズ変化を考慮する。主要な操作のタップ領域は44px以上にする。色だけで状態を伝えず、文字でも「練習」「休憩」「一時停止」を表示する。

### 設定画面

練習時間を最も目立つ設定として置き、休憩時間とセット数を続ける。各値はプリセット、増減操作、直接入力で変更できる。休憩0秒に対応する。セット数とエンドレスは明確に切り替えられる。

入力範囲は練習1〜3,600秒、休憩0〜600秒、セット数1〜999回とする。空欄、小数、範囲外はエラーとして示し、修正されるまで開始できない。エンドレス選択中はセット数の入力を無効にするが、最後に使った有限のセット数は保持する。

有限回では総所要時間を表示する。計算は「練習時間 × セット数 ＋ 休憩時間 × (セット数 − 1)」。エンドレスでは総所要時間の代わりに「終了するまで繰り返す」と表示する。大きな開始ボタンから練習を始める。

### 練習画面

現在の状態、大きな残り時間、現在のセット数を表示する。有限回は「2 / 3」、エンドレスは「2セット目」のように表示する。休憩中は直前に終わったセットと次のセットを区別できる補助表示を用意する。円形の進捗表示を添え、数字の位置は状態が変わっても動かさない。

残り時間は分:秒とし、端数は切り上げる。進行中に「0:00」が長く残る表示を避ける。一時停止中はその状態を明記する。一時停止または再開の大きなボタンと、終了ボタンを配置する。終了を押したときはまず一時停止して確認を挟み、キャンセル時も一時停止を保つ。

### 完了画面

全セット終了を明確に表示し、実施したセット数と設定を示す。「同じ設定でもう一度」と「設定に戻る」を用意する。エンドレスを手動終了した場合は「練習を終了」と表示し、完了したセット数を示す。途中終了を全セット達成として扱わない。

## タイマーと中断時の動作

状態は設定待ち、練習、休憩、一時停止、完了に分ける。一時停止では元の状態、残り時間、セット数を保持する。練習・休憩の実行中に設定は変更できない。

初回の開始は設定した練習時間から始まる。セットのカウントは練習を完了したときに進める。休憩0秒の場合は直接次の練習に進む。有限回の最後の練習が終われば直ちに完了する。

毎回1秒を引く方式ではなく、単調増加する時計の期限から残り時間を計算し、表示更新の遅れによる積み重なる誤差を防ぐ。表示更新が遅れた場合も状態遷移とセット数を正しく計算する。過ぎた境界の音をまとめて連続再生しない。

画面が非表示になったことを検出したら、残り時間を保持して一時停止し、画面維持と音の再生を止める。復帰しても自動で時間を進めず、再開ボタンを表示する。ブラウザの都合で非表示の検出自体が遅れる可能性はあるため、ロック中の時間や合図の正確さを保証する設計にはしない。

ページの再読み込みでは実行中の練習は再開せず、保存した設定を使った設定画面から始める。

## 音と画面維持

音は Web Audio で短い電子音を生成し、外部音声ファイルに依存しない。開始または再開のユーザー操作から音を有効化する。音のオン・オフと試聴操作を用意する。休憩0秒の境界や最後のセットでは、合図を重ねず、その遷移に合う音を1回だけ鳴らす。

Screen Wake Lock API を機能検出し、表示中かつ実行中に画面維持を要求する。停止・非表示・完了時は解放する。再開時に必要なら取得し直す。未対応、拒否、OSによる解除のときもタイマーは使え、画面維持ができていないことを短く伝える。

通知権限は要求しない。バックグラウンド、ロック中の合図、消音設定にかかわらない音、振動の確実な動作は初版の対象外。これらを模擬するための無音再生なども行わない。

## 保存、オフライン、インストール

入力設定と音の設定を localStorage に保存する。保存内容は読み込み時に検証し、不正な内容や保存機能の利用不可では初期値または現在の有効な設定で動作を続ける。練習履歴、個人情報、分析データは保存・送信しない。

Web App Manifest、アイコン、Service Worker を用意する。初回にアプリの主要ファイルをキャッシュしてからオフライン利用可能になる。アプリ表示中にネットワークやCDNから画像、フォント、音などを取得する必要がない構成にする。

更新で実行中のタイマーが消えないよう、Service Worker の更新は練習中に強制反映しない。HTTPS で提供したページを Safari で開き、「共有 → ホーム画面に追加」する手順を案内する。初回からオフラインでインストールできるとは案内しない。

## 技術構成と責務

TypeScript と Vite による小さな単一ページアプリとする。バックエンド、ログイン、データベース、有料サービスは必要としない。

- タイマー：UIやブラウザAPIに依存しない状態遷移と時間計算。
- 画面：設定入力、状態表示、操作、アクセシビリティ。
- 音：音の有効化と各合図の生成。
- 画面維持：Wake Lock の取得、解放、利用不可の扱い。
- 保存：設定の検証と永続化。
- PWA：マニフェスト、キャッシュ、更新、ホーム画面追加の案内。

秘密情報や実行時環境変数は必要としない。公開先の選択と本番公開は別工程であり、この仕様の承認だけで外部への公開は行わない。

## 検証と完了条件

タイマーの自動テストで、40秒・5秒・3セットの合計130秒、1セット、休憩0秒、エンドレス、一時停止・再開、終了、遅れた表示更新、最後の休憩省略を確認する。設定の検証、保存機能が使えない場合、画面維持が利用不可の場合も確認する。

実際のブラウザで設定から完了まで操作する。短い時間に設定した有限回とエンドレスを使い、表示、セット数、合図の呼び出し、中断・再開を確認する。非表示時の一時停止と復帰時の明示的な再開も確認する。オフラインの再読み込みは初回キャッシュ完了後にネットワークを遮断して検証する。

ビルドと型チェックを通す。320px、375px、および広い画面で、設定・実行・一時停止・完了のスクリーンショットを確認する。タップ領域、コントラスト、キーボード操作、動きを減らす設定を確認する。残り秒を毎秒スクリーンリーダーに読み上げさせず、状態の切り替えを通知する。

iPhone SE でホーム画面追加、実際に聞こえる合図、自動ロック防止、手動ロック・復帰、オフライン起動を最終確認する。クラウドでの検証と未実施の実機確認を分けて報告する。

## 初版に含めない機能

練習メニューの名前・右左の自動表示、複数メニューの連結、アカウント、同期、練習履歴、SNS共有、ネイティブアプリ配布、ロック中の通知は含めない。ユーザーは同じタイマーを使って右・左などを自分で切り替えて練習できる。
