# COURT CLOCK

バスケットボールの練習に使う、ホーム画面に追加できる Web タイマー。
黒を基調に、練習はオレンジ、休憩はグリーン。iPhone SE の小さな画面でも、残り時間を大きく表示します。

## 使い方

1. 練習時間・休憩時間・セット数を選びます。プリセット、増減ボタン、直接入力が使えます。
2. 「練習を開始」を押すと、音で練習と休憩の切り替えを知らせます。
3. 一時停止・再開・終了ができます。同じ設定でもう一度始めることもできます。

初期値は **40秒・休憩5秒・3セット**。

**40秒 → 5秒 → 40秒 → 5秒 → 40秒 → 完了**（合計2分10秒）

1セットは練習1回です。最後のセットの後に休憩は入りません。エンドレスでは自分で終了するまで繰り返します。練習時間は1〜3,600秒、休憩は0〜600秒、セット数は1〜999回です。設定と音のオン・オフを端末に保存します。

## iPhone のホーム画面で使う

ビルドした `dist/` を HTTPS の静的サイトとして提供し、そのページを iPhone の Safari で開きます。公開先の選択と本番公開は未実施です。このリポジトリだけでは公開 URL は作られません。

Safari の **共有 → ホーム画面に追加** を選んでください。必要なファイルの初回保存が完了してからは、オフラインでも起動・練習できます。ブラウザがサイトデータを削除した場合は、もう一度オンラインで開いてください。

練習中は画面を表示したまま使います。対応環境では自動ロックを防ぎます。別アプリへの移動・手動ロックでは一時停止し、戻った後は「再開」を押します。ロック中の通知はありません。画面維持が利用できない場合は、表示された案内に従って自動ロック設定を確認してください。

音の有効化には開始・再開・試聴のタップを使います。iPhone の音量・消音設定などによる実際の聞こえ方は実機で確認してください。OS による停止の検出が遅れる場合もあるため、バックグラウンドでの合図の正確さは保証しません。

## 開発

Node.js **22.12以上の22系、24系、または26以上**と npm を使います。クラウドでの確認環境は Node.js 24 / npm 11。既存のチェックアウトを利用し、追加の Git worktree は必要ありません。

```sh
npm ci
npm run dev
```

`.npmrc` により npm キャッシュは書き込み可能なプロジェクト内 `.npm-cache/` を使います。ログイン、秘密情報、API、データベース、外部フォント・音声サービスは不要です。

## 検証とビルド

```sh
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Playwright は本番ビルドを起動し、操作・レスポンシブ表示・音の生成・オフライン・更新待機を検証します。クラウドではインストール済みの `/usr/bin/chromium` を使います。そのブラウザがないローカル環境では、一度 `npx playwright install chromium` を実行してください。

```sh
npm run preview
```

ビルドは `dist/` に出力されます。キャッシュ用の Service Worker は内容のハッシュから生成され、開いている練習を更新で強制再読み込みしません。相対パスで生成するため、HTTPS サイトのサブディレクトリにも配置できます。開発サーバーでは Service Worker を登録せず、オフライン確認には本番ビルドを使います。

アイコンは生成済みPNGをコミットしています。通常のインストール・ビルドでPythonは必要ありません。再生成する場合のみ、`python3 scripts/generate-icons.py` を使います。

## iPhone SE での最終確認

- [ ] 「音を試す」と短い練習で、開始・切り替え・完了の合図が聞こえる。
- [ ] 表示したまま練習すると自動ロックせず、手動ロックや別アプリへの移動では一時停止する。

この実機チェックは、クラウドの Chromium 検証と分けて実施します。
